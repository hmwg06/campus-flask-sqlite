Phát triển ứng dụng web
Đề cương và hướng dẫn học

HTML, CSS, HTTP và phát triển giao diện Flask.

Mục tiêu: đọc tài liệu, luyện tập câu hỏi và theo dõi kết quả cá nhân.

Nội dung ôn tập:
1. HTML chủ yếu dùng để làm gì?
Gợi ý: Mô tả cấu trúc trang.
2. CSS chủ yếu dùng để làm gì?
Gợi ý: Định dạng giao diện.
3. Phương thức HTTP nào thường dùng để đọc tài nguyên?
Gợi ý: GET.
4. Mã HTTP nào thể hiện không tìm thấy tài nguyên?
Gợi ý: 404.
5. Thẻ nào tạo liên kết trong HTML?
Gợi ý: a.
6. CSRF token giúp hạn chế loại yêu cầu nào?
Gợi ý: Yêu cầu giả mạo từ trang khác.

Hoạt động: làm ít nhất 4 câu, xem lại câu sai, sau đó thử lại.
Nguồn: Bộ dữ liệu trình diễn M10 do hệ thống tạo.
Quyền sử dụng: chỉ dùng minh họa chức năng.
